# Submission checklist

- Record baseline health, branch and existing edits.
- Trace main.tex includes; ensure every intended section is reachable.
- Check label definitions and all callers; inspect bibliography keys.
- Use macros consistently and resolve pending source comments.
- Regenerate CSV, table and figure from the same experiment parameters.
- Compile the full document and inspect the log, including warnings.
- Run strict health and evals; inspect PDF layout when rendering is available.
- Review diff for accidental research-claim changes and generated-file edits.
- Report exact evidence, remaining warnings and unverified properties.
