# Intentional workshop defects

This draft is deliberately unsuitable for submission. Stages 1–4 add agent
customization without repairing it; Stage 5 repairs it. Instructor inventory:
wrong theorem reference and citation key, literal root notation instead of the
shared macro, a pending comment, mismatched figure name, an incorrect manual
table, stale CSV, tracked auxiliary file, omitted conclusion, and incomplete
build instructions. The mathematical proof itself is intended to be correct.
Do not treat expected failure in early stages as a successful check.
